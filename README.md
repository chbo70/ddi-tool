# ddi-tool
Drug-Drug Interaction Tool for the Lecture "Medizinische Entscheidungsunterstützung" at the Medical University Vienna.

With the Tool you can enter two different drugs and see the interaction between them.


## Dependencies
- docker
- docker compose

## Run the Application 

To build the backend and frontend:
```
docker compose build
```

Start up the backend and frontend:
```
docker compose up -d
```

The Drug-Drug Interaction Tool is available under:

```
localhost:8080
```
